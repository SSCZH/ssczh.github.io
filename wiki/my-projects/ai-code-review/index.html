AI Code Review

项目简介

基于 AI 的自动化代码审查工具，帮助开发者在提交代码前自动发现潜在问题和优化建议。

核心功能

  • 自动分析代码变更（Git Diff）
  • 基于大语言模型生成审查意见
  • 支持多种编程语言
  • 集成 CI/CD 流程
